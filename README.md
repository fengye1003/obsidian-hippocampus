# obsidian-hippocampus

> 给 AI Agent 装一个放在你硬盘上的海马体：**Obsidian 库 + 三级置信度 + 会遗忘的记忆**。
> 纯文本、可读、可改、可搬走；模型会换、会话会断、上下文会丢，库不会。

这是一个单文件 DSH skill + 一套目录规范 + 一份 `AGENTS.md` 模板。复制、改、再分发都可以（MIT）。

---

## 它解决什么

- 上周说过的偏好，这周它又问一遍；
- 项目聊到一半关掉，下次它完全不记得；
- 换了个模型，之前的一切归零。

这不是模型笨，是它没有「体外记忆」。这套方案做的事情很简单：给 agent 一个放在你硬盘上的海马体。

它抄的是人脑海马体的三件事：

| 机制 | 做法 |
|---|---|
| 巩固 consolidation | 每次里程碑结束就落盘，不等会话结束 |
| 分级 graded storage | F0 模糊 / F1 验证 / F2 稳定，三级置信度 |
| 遗忘 forgetting | 每周回访：过期标掉、重复合并、被推翻就降级 |

普通「聊天记忆」= 模型上下文，会话一关就没了；RAG = 按相似度捞片段，适合找资料，不适合记住一个人。
这套方案 = 一个**你能打开、能审、能改、能搬走**的文本库，agent 每次开机先读它。

---

## 三分钟装好

1. 把 [`skills/obsidian-hippocampus/SKILL.md`](skills/obsidian-hippocampus/SKILL.md) 复制到 `~/.dsh/skills/obsidian-hippocampus/SKILL.md`（Windows：`%USERPROFILE%\.dsh\skills\`）。
2. 让 DSH 在**你的 Obsidian 库根目录**启动（工作目录 = 库根）。
3. 对 agent 说：**「用海马体方案初始化这个库」**。
4. 它会先问你四个问题，再建 `.AGENT/` 与 `AGENTS.md`，最后做一次读写验收。

装完的判据：**新开一个会话，它能说出上次对话里的一件小事，并说得出这条记忆存在哪个文件里。**

> `AGENTS.md` 是按**会话工作目录**注入的，不是按库的位置找的。工作目录必须是库根。

## 典型结构

```
<库根>/
├── AGENTS.md                  # 规则（每次会话自动注入，必须短）
└── .AGENT/                    # agent 的地盘（隐藏目录，不进图谱）
    ├── README.md              # 完整流程与目录地图
    ├── 01-画像/
    │   ├── 用户画像.md         # 稳定身份、偏好、底线、禁记清单
    │   └── 助手画像.md
    ├── 02-记忆库/
    │   ├── 记忆索引.md         # 关键词 → 位置（先读它，再读正文）
    │   ├── 长期记忆.md         # 稳定事实、结论、踩坑（F1/F2）
    │   ├── 近期状态.md         # 正在发生、情绪、下一步
    │   ├── 项目档案.md         # 项目细节、进展、待办
    │   └── 会话日志/           # 一篇会话一个文件
    ├── 03-工作区/              # 临时产物、脚本、原始数据
    └── 04-外部引用/            # 只存链接，不复制正文
```

三层流向：

```
当前会话（工作记忆）
   │  里程碑：巩固
   ▼
近期状态（几天~几周，会过期）
   │  反复出现 / 用户确认：升级
   ▼
长期记忆 + 项目档案（稳定事实，带日期与来源）
   │  每周回访：合并 / 降级 / 删除
   ▼
会话日志（只留过程，不占日常读取）
```

详细职责见 [docs/structure.md](docs/structure.md)。

## 三条最关键的设计取舍

**1. 为什么放隐藏目录 `.AGENT/`**
不进 Obsidian 图谱、不干扰搜索、明确「这是 agent 的地盘」；代价是个别同步工具会跳过 `.` 开头的目录，需要单独处理。

**2. 为什么不上向量库 / RAG**
几百条记忆用「索引 + 分层读取」完全够。上了向量库反而引入新的不确定性；等索引一页放不下再考虑。

**3. 为什么 `AGENTS.md` 必须很短**
它每次会话都注入，有硬预算。我们自己的 `AGENTS.md` 曾经涨到 66,170 字节，超过 64 KB 注入预算，**尾部约 930 字节每次都被静默截掉** —— 写在后面的规则等于没写。
现在 27 KB：判据留在 `AGENTS.md`，操作细节下沉到各工具 README，用指针连接。完整教训见 [docs/lessons.md](docs/lessons.md)。

## 最小闭环

如果只记住三件事：

1. **开始读**：索引 → 长期 → 近期。
2. **结束写**：近期状态、项目档案、一篇会话日志。
3. **每周删**：过期、重复、没验证的。

这套方案的门槛不在技术，在纪律：**每次结束都写，每周都删。**
