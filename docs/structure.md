# 典型结构：每一层该放什么

> 这份文档回答一个问题：**一条新信息，今天该写进哪个文件？**

## 1. 目录树

```
<库根>/
├── AGENTS.md                  # 规则：只放判据与指针，每次会话自动注入
├── Agent速报/                 # 可选：手机上一屏能读完的成稿（可见区）
└── .AGENT/
    ├── README.md              # 完整流程、目录地图、维护手册
    ├── 01-画像/
    │   ├── 用户画像.md
    │   └── 助手画像.md
    ├── 02-记忆库/
    │   ├── 记忆索引.md
    │   ├── 长期记忆.md
    │   ├── 近期状态.md
    │   ├── 项目档案.md
    │   └── 会话日志/
    │       └── YYYY-MM-DD-主题.md
    ├── 03-工作区/              # 临时产物、脚本、原始数据（可清理）
    └── 04-外部引用/            # 链接索引，不复制正文
```

## 2. 职责表

| 层 | 位置 | 存什么 | 更新时机 | 体量上限（建议） |
|---|---|---|---|---|
| 规则 | 库根 `AGENTS.md` | 判据 + 指针 | 很少改 | 60 行 / 6k 字 |
| 说明 | `.AGENT/README.md` | 完整流程、目录地图 | 结构变化时 | 150 行 |
| 画像 | `01-画像/` | 稳定身份、偏好、底线、禁记清单 | 低频，确认后 | 每人 1 页 |
| 长期 | `02-记忆库/长期记忆.md` | 稳定事实、结论、踩坑经验 | 有新 F1/F2 | 15k 字，超了下沉 |
| 近期 | `02-记忆库/近期状态.md` | 正在发生、情绪、下一步 | 每个里程碑 | 最近 2~4 周 |
| 项目 | `02-记忆库/项目档案.md` | 目标、进展、决策、待办 | 有进展时 | 每项目半页 |
| 流水 | `02-记忆库/会话日志/` | 单次会话的过程与遗留 | 每个里程碑 | 一篇一文件 |
| 检索 | `02-记忆库/记忆索引.md` | 关键词 → 位置 | 有新条目时 | 一页 |
| 草稿 | `03-工作区/` | 临时产物、脚本、原始数据 | 随时，可清理 | 不限，定期清 |
| 引用 | `04-外部引用/` | 只存链接与出处 | 按需 | 一页 |

## 3. 命名规则

- 会话日志：`YYYY-MM-DD-主题.md`，主题 3~8 个字；
- 索引格式：`关键词 → 文件#小节`，**不要写摘要**；
- 跨文件引用写**从库根算的路径**，别用 `../`，搬目录不会断。

## 4. 落点示例

| 用户说 | 类型 | 写到哪 | 置信度 |
|---|---|---|---|
| 「下周三要交报告」 | 有时限的任务 | 近期状态 + 项目档案 | F1 |
| 「我讨厌被叫全名」 | 稳定偏好 | 用户画像 | F1 → 复现后 F2 |
| 「我可能在考虑出国」 | 模糊意向 | 只进会话日志，用于下次提问 | F0 |
| 「这台机器是 Python 3.11」 | 环境事实 | 长期记忆·工具 | F1 |
| 「今天被老师骂了，很烦」 | 情绪 | 近期状态（会过期），不进长期 | F1 |
| 「我的 API key 是 sk-…」 | 秘密 | 拒绝落盘，只记「在哪取」 | — |
| 「以后回答短一点」 | 沟通偏好 | 用户画像 | F1 |
| 「我改主意了，不出国了」 | 推翻旧结论 | 长期记忆降级 + 日志留痕 | F1 |

## 5. 读取顺序（会话开始）

1. `.AGENT/README.md` —— 规则与目录；
2. `记忆索引.md` —— 先定位，别整库灌；
3. `长期记忆.md` —— 稳定事实与偏好；
4. `近期状态.md` —— 最近在忙什么；
5. 只在话题相关时读 `项目档案.md` 与对应日期的会话日志。

时间紧时至少读「索引 + 长期 + 近期」三份。
