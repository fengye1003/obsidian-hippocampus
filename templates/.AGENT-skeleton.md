# `.AGENT/` 种子文件清单

初始化时**先建骨架，不编内容**。未知项一律写「待确认」，不要用合理猜测填空。

| 文件 | 初始内容 | 不要写什么 |
|---|---|---|
| `AGENTS.md` | 从 `templates/AGENTS.md` 复制，按库的实际情况改铁律 | 不要复制整份说明，避免两处打架 |
| `.AGENT/README.md` | 读取顺序、写入规则、目录地图、维护节奏 | 不要重复 `AGENTS.md` 的判据 |
| `01-画像/用户画像.md` | 称呼、时区/作息、沟通偏好、禁记清单 | 不要写没确认过的推断 |
| `01-画像/助手画像.md` | agent 的名字、语气、边界 | 不要写成产品说明书 |
| `02-记忆库/记忆索引.md` | 「关键词 → 文件#小节」的空表 + 3 条示例 | 不要放正文摘要 |
| `02-记忆库/长期记忆.md` | 分节：身份 / 偏好 / 稳定事实 / 踩坑经验 / 工具 | 不要写推测、不要写一次性事件 |
| `02-记忆库/近期状态.md` | 时间轴（倒序）+ 推进中 + 情绪 + 下一步 | 不要写成日记 |
| `02-记忆库/项目档案.md` | 一个项目一节：目标 / 现状 / 决策 / 待办 | 不要混进个人情绪 |
| `02-记忆库/会话日志/` | 空目录，本次初始化写第一篇 | 不要把所有日志塞进一个文件 |
| `03-工作区/` | 空目录 + 一句「可清理」 | — |
| `04-外部引用/` | 空目录 + 一句「只放链接」 | 不要复制网页正文 |

## 初始化四问（先问，再动手）

1. Obsidian 库的绝对路径是哪个？现在的工作目录是它吗？
2. 允许在库里新建 `.AGENT/`（隐藏目录）和根目录的 `AGENTS.md` 吗？
3. 这个库有没有 git / 云同步？有没有第二台设备同时用？
4. 有没有**绝对不能记**的东西？（真实姓名、公司、客户、健康、财务、家庭……）

第 4 问的答案写进 `01-画像/用户画像.md` 的「禁记清单」，**优先级高于一切记忆规则**。

> 别覆盖已有的 `AGENTS.md`：先完整读一遍，再把模板的章节**合并**进去，保留原有内容。

## 当场验收（四测，缺一不可）

1. **写入**：让用户说一件近期的小事，写进 `近期状态.md`；
2. **读取**：请用户**新开一个会话**，问「我最近在忙什么」，能答出且说得出存在哪个文件；
3. **边界**：让用户说「这条别记」，确认全库搜索不到；
4. **死链**：`记忆索引.md` 里每条链接都能打开。

四项全过再宣布「装好了」。
